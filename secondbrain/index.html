second-brain-os: Claude files, links and maintains everything you save

You save articles, videos and screenshots and never look at them again. This setup hands the boring part to Claude: every source becomes a plain markdown page, linked to what you already know, kept tidy on a schedule, and you can ask it questions.

1Set it up

The easy way: open Claude Code and paste this:

Set up my second brain from https://github.com/undefined-ui/second-brain-os in ~/brain: copy the vault template, put the skills, commands and agents into ~/brain/.claude and the scripts into ~/brain/scripts.

Or do it yourself with the README's quickstart:

git clone https://github.com/undefined-ui/second-brain-os.git
cp -r second-brain-os/vault-template ~/brain

mkdir -p ~/brain/.claude
cp -r second-brain-os/skills   ~/brain/.claude/skills
cp -r second-brain-os/commands ~/brain/.claude/commands
cp -r second-brain-os/agents   ~/brain/.claude/agents
cp -r second-brain-os/scripts  ~/brain/scripts

rm ~/brain/.claude/*/README.md ~/brain/scripts/README.md
cd ~/brain && claude

Then install Obsidian (free) and open ~/brain with "Open folder as vault". That's where you see the graph.

Windows: use python wherever the guide says python3. The python3 name usually points to the Microsoft Store stub and does nothing.

2Feed it

Clip an article into raw/ (the Obsidian Web Clipper does it in one click), then run:

/ingest

For a video or podcast use /ingest-youtube, for a PDF /ingest-pdf. Old Claude or ChatGPT exports go through the chat-import skill, which does a privacy pass first and lets you decide what gets in. The author's advice: feed it ten sources before you judge it.

3Ask it, and put it on autopilot

Ask questions with /ask; answers cite your own pages. Test yourself with /quiz. Then run:

/schedule

It proposes a schedule for ingest, link, lint and review that fits how much you add, with the exact prompt for each task, so the vault files itself while you're away.

What's inside

18 skillsingest, query, graph, lint, merge, quiz, review, report, write, publish, privacy, project, metrics, rename, backfill, transcript, chat-import, changed-my-mind.
72 slash commands + 6 subagentsScoped entry points like /ingest-youtube, /orphans, /contradictions, /weekly. Subagents: curator, graph-analyst, ingestor, linker, researcher, reviewer (four of them read-only).
Nothing is ingested until it is linkedA new page connects to what's already there in the same run, so the vault gets better as it grows instead of just bigger.
Contradictions are recorded, never overwrittenWhen a new source disagrees, both positions stay with dates and sources: the history of what you believed and why.

Honest notes

  • The repo is free (MIT) and so is Obsidian. Claude Code itself needs a Claude plan.
  • It's for people who read and save a lot. The README says it plainly: it won't organise a vault you never add to, and it's not a team wiki.
  • Everything stays plain markdown in a folder you own. Walk away from every tool and you keep the notes.
  • The notes, chats and quiz in the Instagram video are illustrations drawn for the video; the numbers (750 stars, 18 skills, 72 commands) come from the repo and its README.
