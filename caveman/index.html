What it does

Your agent bills by the token and writes like it knows that. Caveman is a skill (a rules file) that makes the agent answer short. Same diagnosis, same fix, fewer words. From the repo's own example:

Normal agent · 69 tokensThe reason your React component is re-rendering is likely because you're creating a new object reference on each render cycle. When you pass an inline object as a prop, React's shallow comparison sees it as a different object every time, which triggers a re-render. I'd recommend using useMemo to memoize the object.
Caveman agent · 19 tokensNew object ref each render. Inline object prop = new ref = re-render. Wrap in useMemo.
What stays untouched: code, commands, file paths and exact error messages are never cavemanned, only the prose around them. Security warnings and "are you sure?" confirmations come back in full sentences.

1Install the skill (one command)

No account, no API key. Works for Claude Code, Codex, Gemini CLI, Cursor, Windsurf, Cline, Copilot and more:

npx skills add JuliusBrussee/caveman -g

Only Claude Code? Use the plugin route instead:

claude plugin marketplace add JuliusBrussee/caveman
claude plugin install caveman@caveman

If the agent doesn't switch on its own, type /caveman.

2Turn the dial

/caveman liteTight but polite. Good default for shared repos.
/caveman ultraGrunts only. Half the fun is that it is still right.
/caveman-commitWrites a one-line Conventional Commit.
/caveman-reviewOne finding per line: L42: 🔴 null deref. Guard it.
/caveman-compress CLAUDE.mdShrinks your memory files, keeps every heading, path and command, backs up the original.
stop cavemanNormal prose returns. No hard feelings.

3The numbers (the honest version)

  • JetBrains, 86 real coding tasks, paired A/B, skill only: 8.5% fewer output tokens, about 10% cost, no detectable quality change (sign test p = 0.82).
  • Adobe Research (CAVEWOMAN, arXiv 2606.24083), eight models, five datasets: caveman-style output cuts realized cost 1.4 to 2.4× per model, up to 3×.
  • The repo's own eval, ten dev questions vs. a plain "answer concisely" control: 50% fewer output tokens at the median.
Read those together: chat-style Q&A gets a big cut. In long agentic sessions most tokens are code and tool output, which the skill never touches, so the saving on the bill is smaller there. That is why the same project ships a proxy (npm install -g @caveman-ai/cli) that shrinks what the agent reads: logs, test output, JSON, diffs. Start with the skill; graduate to the proxy if the bill says so.

Good to know

  • Caveman never rewrites your prompts, only the agent's answers. The Adobe paper found that compressing the human's prompt makes models answer longer and worse.
  • The skill is MIT and free forever. The proxy is an MIT CLI with a BSL-1.1 runtime.
  • Changed your mind: npx -y github:JuliusBrussee/caveman -- --uninstall
