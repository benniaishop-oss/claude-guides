The Karpathy CLAUDE.md: one file that fixes Claude Code's worst habits

A single rules file derived from Andrej Karpathy's notes on how LLMs go wrong when they code. Over 214,000 stars on GitHub. Install takes one line.

GitHub: multica-ai/andrej-karpathy-skillsAbout 2 minutesFree, MIT

Repo: github.com/multica-ai/andrej-karpathy-skills

What it fixes

Karpathy's complaints, in short: the model makes assumptions on your behalf and runs with them, overcomplicates code and APIs, and changes code it doesn't understand as a side effect. The file answers with four principles:

1. Think before codingState assumptions out loud. If something is ambiguous, ask instead of guessing. Push back when a simpler route exists.
2. Simplicity firstThe minimum code that solves the problem. No speculative features, no abstractions for single-use code. If 200 lines could be 50, rewrite.
3. Surgical changesTouch only what you must. Don't "improve" adjacent code. Clean up only the mess your own change created.
4. Goal-driven executionTurn tasks into verifiable goals: write the test first, then loop until it passes.

AInstall as a plugin (all projects)

Inside Claude Code, add the marketplace, then install:

/plugin marketplace add forrestchang/andrej-karpathy-skills
/plugin install andrej-karpathy-skills@karpathy-skills

BOr drop the file into one project

From the project folder:

curl -o CLAUDE.md https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md

Already have a CLAUDE.md? Append instead of overwriting:

curl https://raw.githubusercontent.com/forrestchang/andrej-karpathy-skills/main/CLAUDE.md >> CLAUDE.md
How it works: Claude Code reads CLAUDE.md at the start of every session. Whatever is in there shapes how it behaves in that project. No restart, no config.

Good to know

  • Rules are guidelines, not laws: the file tells Claude to name tradeoffs and ask, so expect more questions on ambiguous tasks. That's the point.
  • You can edit the file. Keep what matches how you work, cut what doesn't.
  • Pair it with your own project rules below the Karpathy block; Claude reads the whole file.
