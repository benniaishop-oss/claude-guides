GenOffice: let Claude build your PowerPoint for you

A free, open-source Office suite for Mac, Windows and Linux with an AI agent next to every document. It opens and saves real .docx, .xlsx and .pptx files. Connect it to Claude Code and Claude builds decks, spreadsheets and documents for you, then checks its own work.

GitHub: genspark-ai/genofficeApache-2.0Free for individuals and teams

Repo: github.com/genspark-ai/genoffice

1Download the app

Grab the installer for your computer from the latest release: .dmg for macOS (Apple Silicon or Intel), -x64.exe for most Windows PCs (-arm64.exe for Snapdragon), .deb / .rpm / .AppImage for Linux. The macOS and Windows installers are signed.

Open it once and pick how the AI runs: sign in with Genspark (nothing to configure), or go to Settings → AI and paste your own key for Claude (or OpenAI, Gemini and others).

2Connect it to Claude Code

Paste this one line in your terminal:

claude mcp add --transport stdio genoffice -- genoffice mcp
If Claude Code can't find genoffice: the command ships inside the app. Open GenOffice and go to Settings → Integrations → MCP. It shows the exact path for your install and a copy-ready line. On macOS it is /Applications/GenOffice.app/Contents/Resources/cli/genoffice.

Prefer a skill over MCP? In the app, Settings → Integrations lists the coding agents it finds on your computer and installs the GenOffice skill into Claude Code with one click. Or run:

npx skills add genspark-ai/genoffice

Claude Desktop, Cursor and other MCP apps use this JSON block instead:

{ "mcpServers": { "genoffice": { "command": "genoffice", "args": ["mcp"] } } }

3Ask for your first file

Start a new Claude Code chat and just say what you need. For example:

Build an eight-slide investor briefing about renewable energy in 2026, with a real photo on the cover.

That is the prompt from the GenOffice README. With only the MCP server attached, Claude made 38 tool calls in about thirteen minutes: it pulled the figures and photos, wrote an outline, built each slide, rendered every page to look at it, and rebuilt the three it didn't like. The result is a normal .pptx you can keep editing.

What else it does

SlidesOne sentence in, a designed deck out. Every slide stays editable.
SheetsAdds live formulas (real SUMIFs, not pasted numbers) and charts, applied as one undoable batch. Ask a question about the workbook and it cites the cells it used.
DocsEdits your Word file and shows exactly what it touched: tracked changes, and every AI turn can be rolled back.
PDFEdit text inside the page, or convert PDF to Word, Excel or PowerPoint on your own computer. Scans go through system OCR.
Markdown + HTMLA block editor for .md and an AI page builder that writes a single .html file.

Honest notes

  • The app is free. The AI calls go through Genspark if you sign in, or through your own API key if you bring one, and that provider's pricing applies.
  • Files open, edit, save and convert on your machine. Only the AI calls (and web or image search, if used) leave it.
  • Parts of a file you did not touch are kept byte for byte, so documents still open fine in Word, Excel and PowerPoint.
  • GenOffice is made by Genspark, not by Anthropic. It works with Claude, and with other models too.
  • Open source under Apache-2.0.
