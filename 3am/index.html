The 3 AM prompt: make viral motion graphics with Claude

You saw Sleep and Overthinking fight for the #1 spot until the alarm clock took it. No After Effects, no editor: Claude writes the whole animation as code, and a browser turns it into video. Here is the exact prompt and two ways to get your own video out of it.

Works with Claude Opus 5.5Claude app or Claude CodeNo design skills needed

1The exact prompt

This is the prompt from the video. Copy it as it is, or swap the two fighters and the twist for your own idea:

Create a playful 15 second motion graphic where Sleep and Overthinking fight for the #1 spot at 3 AM, through UI elements: a leaderboard, a chat, progress bars. At the end the alarm clock takes it.

Add these lines under it. They are what makes the result look designed instead of random:

Format: vertical 1080x1920. Build it as one HTML file.
Style: white and light blue, chunky rounded cards with a dark outline, one accent colour, bold Inter type.
Characters: draw each fighter as a simple SVG icon (a blue moon for Sleep, a dark spinning scribble for Overthinking, a red alarm clock).
Motion: springs with a little bounce, every change lands on a beat, nothing stays still for more than 2 seconds.
End card: a big line of text with my call to action.

2The quick way: Claude app

Paste the prompt into claude.ai (or the desktop app). Claude builds the animation as an artifact you can watch right in the chat. Say what to change ("slower", "make the chat funnier", "bigger text") until you like it.

To get a video file, open the artifact full screen on your phone or in a narrow browser window and screen record it. Crop to 9:16 and you are done.

Tip: ask Claude to "add a 1 second pause at the start and a replay button" so your screen recording starts clean.

3The pro way: Claude Code renders a real MP4

In Claude Code Claude can render the video itself, frame by frame, so it is perfectly smooth and exactly 1080x1920. Add this to the prompt:

Write it so that a function window.render(t) draws the exact frame for time t in seconds (no timers, no CSS animations), and set window.END to the length.
Then write a small Python script with Playwright that opens the page, calls render(i / 30) for every frame, screenshots each one and joins them into final.mp4 with ffmpeg. Run it and show me the result.

Claude installs what it needs (Playwright and ffmpeg), renders, and you get final.mp4 ready for Reels, TikTok and Shorts.
