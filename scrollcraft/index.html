scroll-craft: Claude builds a scroll-driven website that looks like nobody else's

Describe your brand. Claude picks one of eight page grammars, plans a feeling for every section, gives the site its own signature interaction, refuses the layouts that make AI pages recognisable, and then opens the finished page in a real browser to check every scroll position before it hands it over.

GitHub: nateherkai/scroll-craftMITClaude Code plugin · also Codex

Repo with the ten-site walkthrough video: github.com/nateherkai/scroll-craft

1Install it

Claude Code: paste this and Claude sets it up for you:

Install this plugin for me: https://github.com/nateherkai/scroll-craft

Or run the two commands from the README yourself:

/plugin marketplace add nateherkai/scroll-craft
/plugin install nateherk-design

If the install summary says Run /reload-plugins to activate., run that.

You need Node 18+ and a full ffmpeg build (for scroll-scrubbed video), plus playwright-core and Chrome for the browser check. On the first run, the README says to start with the doctor script, which finds a working ffmpeg and flags setup problems before they turn into confusing errors. You can simply ask Claude to run it.

2Describe your site

Use the skill by describing what you want, or call it directly:

/nateherk-design:scroll-craft
Build a scroll-driven landing page for my protein coffee brand. Loud, filmic, product first. Use my photos in ./assets.

Give it your brand kit if you have one: its hard rules win over the skill's own taste. Point it at your own photos and footage and the whole build costs nothing.

3Let it check its own work

When the page is built, a headless browser walks it at every scroll position and reports dead scroll, captions that never reach full opacity, contrast per line and videos that never decoded. Then it writes a contact sheet so you can see the whole page at a glance.

What's inside

8 page grammarsFilmic one-shot, chaptered editorial, live surface, continuous world, typographic poster, gallery, split stage, rhythmic cutlist. Each forbids what the others require, so two builds can't quietly converge.
Signature move + fingerprint gateEvery build invents one bespoke interaction. A new build must differ from your earlier ones on at least 4 of 6 dimensions: grammar, nav, hero, act shape, close, signature move.
Refuse listIdentical feature-card grids, 01 / 06 counters, scroll cues, gradient text, invented statistics, fake dashboards, AI-purple gradients.
Ten approved sitesThe process behind AI Automation Society, PERKFORM, Glaido, Herkules Advisory, Serein, FORME, Pelagic, NOEMA, OFFGRID and Afterhours is documented as worked examples.

Honest notes

  • The skill is free (MIT). Building from your own photos and footage needs no key and no spend. Generated images and video are optional and not free: they need a KIE_AI_API_KEY and cost real money.
  • The author says it has only ever been run on Windows; macOS and Linux should work but are untested.
  • It's opinionated on purpose. It will argue with you about your layout. If you want a page that looks like everything else, it's the wrong tool.
  • The browser mockups, the coffee brand and the contrast values in the Instagram video are illustrations drawn for the video; the numbers (2,810 stars, eight grammars, ten sites, 4 of 6 gate, the 2.1:1 example) come from the repo and its README.
