ECC: one plugin, 68 agents, 292 skills

ECC turns Claude Code from "writes code when asked" into a working process: plan first, write the failing test first, build until it passes, then let a fresh agent review the result. You install it once instead of repeating it in every prompt.

Repo: github.com/affaan-m/ECC · Website: ecc.tools

What you get

The README sums it up in one line: plan -> test -> implement -> review -> verify -> remember -> improve. The four pieces you will notice first:

/ecc:plan "your feature"The planner agent writes an implementation plan you can edit before a single line of code exists.
tdd-workflowA skill that makes Claude write a failing test first (RED), then implement until it passes (GREEN), then refactor. "Please use TDD" stops being something the model can forget.
/code-reviewThe code-reviewer agent looks at your changes from a fresh context, so the same context that wrote the code is not the one grading it.
/save-session and /resume-sessionEnd a long session with a summary and pick it up later without pasting the whole transcript back in.

Also inside: /build-fix for broken builds, /refactor-clean for dead code, /context-budget when the context window gets heavy, and AgentShield (/security-scan), which scans your prompts, hooks, MCP config and permissions as an attack surface.

1Check the requirements

  • Claude Code 2.1 or newer (claude --version)
  • Node.js 18 or newer and Git

2Install

Option A, guided (recommended by the author). Run this in your terminal (PowerShell on Windows). For a personal setup choose Global user and Standard hooks:

npx ecc-universal@2.2.2 setup

Option B, from inside Claude Code. Two native plugin commands:

/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc

Then start a new Claude Code session and check that ecc@ecc shows up in /plugin list.

Pick one path, not both. Installing ECC twice into Claude Code duplicates skills, commands and hooks. And only install from the official sources: the GitHub repo affaan-m/ECC, the npm package ecc-universal, the plugin ecc@ecc and ecc.tools. The README warns that re-uploads elsewhere may contain malware.

3Run your first feature through it

This is the "new feature" flow from the README:

/ecc:plan "Add user authentication with OAuth"
  • Read the plan, edit it, confirm it.
  • Ask Claude to use the tdd-workflow skill: it writes the failing test first, then the code until the test passes.
  • Run /code-review for the fresh-context review and fix what it finds.

Fixing a bug works the same way: reproduce it with a failing test first, then fix, then review.

4Optional: rules for your language

Plugins cannot ship rules, so ECC's language standards are copied by hand. Take only the common pack plus the one language you actually use:

git clone https://github.com/affaan-m/ECC.git
cd ECC
mkdir -p ~/.claude/rules/ecc
cp -R rules/common ~/.claude/rules/ecc/
cp -R rules/typescript ~/.claude/rules/ecc/

Rules are always loaded, so every extra pack costs context in every session.

Removing it again

Plugin install: open /plugin in Claude Code and uninstall ecc@ecc, then delete any rule folders you copied by hand. Guided install: run these from the same directory you installed from.

npx ecc-universal@2.2.2 uninstall --dry-run
npx ecc-universal@2.2.2 uninstall

ECC only removes files it recorded in its own install-state, nothing else in your ~/.claude.

Honest notes

  • It is big. 292 skills are loaded only when a task needs them, but hooks run on every session. If you want it lighter, the README has a minimal profile without the hook runtime: npx ecc-universal@2.2.2 install --profile minimal --target claude.
  • It works best with Claude Code. Codex, Cursor, Gemini and others get adapters with fewer features.
  • The open-source repo is free under MIT. ECC Pro is a separate paid GitHub App for private repos; you do not need it for anything in this guide.
