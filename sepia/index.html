sepia: make AI writing read like a person wrote it

A free writing skill for Claude Code and 77+ other agents. Most "humanizers" swap words. sepia goes after what actually gives AI away: the structure of the piece. It can write, review, fix only the lines that need it, or rewrite from scratch.

GitHub: Nanako0129/sepiaMIT licenseNo account

Repo: github.com/Nanako0129/sepia

1Install it

One command, works for Claude Code and most other agents (you pick which ones when it asks):

npx skills add Nanako0129/sepia -g

Or as a native Claude Code plugin (terminal):

claude plugin marketplace add Nanako0129/sepia
claude plugin install sepia@sepia --scope user
Easiest of all: paste https://github.com/Nanako0129/sepia into Claude Code and say "install this skill for my user". It runs the commands above for you. The -g / --scope user part means you install once and it works in every project.

2Pick the right command

/sepia-reviewDiagnose only. Paste your draft and it tells you what reads as AI (filler, hedging where a judgment was needed, chatbot leftovers, stamped-out formatting) without touching the text. Start here.
/sepia-refactorMinimal edits. Fixes only the lines that need it and leaves the rest of your writing alone.
/sepia-recreateFull rewrite from the facts and intent of the original, when the draft is beyond saving.
/sepia-writeWrite something new with the rules applied from the start.
/sepia-hemingwayFiction with a built-in Hemingway voice (iceberg omission). Optional.

Plain /sepia routes to the right one on its own.

3Why it works differently

The skill is built on a 2026 study (StoryScope, arXiv 2604.03136) of 61,608 stories written by humans and five frontier AI models. A classifier using only structure spotted the AI stories at 93.2% (macro-F1). When human editors rewrote the surface style, detection barely moved: 95.5% down to 93.9%. So changing words is not enough.

sepia works in three passes: narrative architecture first, then discourse flow (paragraph shape, rhythm), then surface style (cliches, word choice). For professional writing it has separate rules per format: release notes, PR and issue replies, postmortems, tickets, technical articles and long-form journalism.

The part most tools get wrong: it never applies every rule. It picks 3 to 5 moves per story and leaves slack, because a text with every rule applied is a new fingerprint of its own.

Honest notes
